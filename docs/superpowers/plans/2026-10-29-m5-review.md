# M5 · 复习 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每天先复习到期的词（翻面卡片 + 忘了/模糊/记得），再学新句子；首页「今天的学习」加回复习那一格；设置页加「我的生词」列表。

**Architecture:** 复习队列和评分后的顺序是 `study.js` 里的纯函数（Node 测试），间隔用现有的 `SRS.review`。复习画面是学习页 `studyView` 的第四种画面（`phase: "review"`），放在新句子前面：`startStudy()` 先复习，复习完接 `studyNext()`。每张卡评分后立刻存（卡片的 `srs` + `daily.reviewed`），中途退出不丢。「我的生词」是新页面 `wordsView`（设置页进入，DEPTH 2）。

**Tech Stack:** 原生 HTML/CSS/JS，IndexedDB，`node --test`，`tests/browser/run.js`。

**Spec:** `docs/第二三阶段开发规格.md` 5.1（复习数）、5.2（先复习后新学）、6.1–6.3、9 M5；`docs/设计规范.md` 5.4（两格并排）、5.8、5.11、6。

## Global Constraints

- 复习数 = `!known && srs.due <= 现在` 的卡，每次最多 50 张（`STUDY.dueCount` 已有）
- 正面：只显示汉字（大字 72px）+「心里读一遍，再点翻面」；背面：粤拼（声调色）、**翻面时自动朗读**、意思、提示、出处（歌名 + 那一句，「▶ 原唱这句」只播那一句：从这句开始到下一句开始，0.8×，复用学习页的原唱逻辑和错误提示）
- 三个按钮：忘了 / 模糊 / 记得（`again` / `hard` / `good`），每个下面显示预估间隔（「10 分钟」「1 天」「3 天」），用 `SRS.review` 算
- 出处的歌被删了不显示出处；多个出处显示第一个还存在的
- 组件只用 CSS 变量；按钮 ≥ 44px；按下用 `.is-pressed`；不用暗幕；减弱动态只淡入淡出
- 首页卡片排版按设计规范 5.4（两格并排 / 只有一格时紧凑一行 / 今天学完了）
- 删除卡片用 `confirmSheet`
- 测试句子都是编的，不提交歌词/音频
- 完成后直接合并到 main 并 push（CLAUDE.md 固定规则）

**本计划替开发者做的决定（交付前请他确认）：**
1. **复习进度**：一次最多 50 张，顶部用一条连续进度条 +「3 / 12」，不用一格一格（50 格太细）
2. **今天新句子学完了（或没有词汇包、整首学完）但还有到期复习**：首页紧凑一行「复习 **N** 个词」+ 按钮「开始复习」；复习完到完成页
3. **「忘了」的卡**：这一轮最后再出现一次（只再出现一次，第二次还选「忘了」也不再加）
4. **「复习的词」计数**：每张卡第一次评分算一个，再出现的不重复算
5. **复习顺序**：到期早的先复习
6. **「我的生词」入口**放在设置页（一张卡片「我的生词（N）」），点进去是整页列表（从设置页滑入）；列表按下次复习时间排，已认识的排最后、标「已认识」；点一行弹出底部弹窗：大字 + 粤拼 + 意思、🔊、「标记为已认识 / 取消已认识」、红色「删除」
7. 复习页右滑 / × 退出：已经评分的都保存了，下次接着复习剩下的

## Review Focus

1. **同一张卡选了「忘了」，这一轮再出现时又选「忘了」**：不能无限循环 → Task 1 测 `afterGrade: 只再出现一次`
2. **出处的歌被删了 / 那一句被编辑歌曲删掉了（`li` 超出）**：不显示出处、不报错 → Task 3 页面测试
3. **复习中途退出，再进来**：已评分的卡 due 已经变到以后，不再出现；`daily.reviewed` 不重复加 → Task 3 页面测试
4. **到期卡超过 50 张**：这次只复习 50 张，首页显示 50 → Task 1 测 `reviewQueue: 最多 50`
5. **凌晨 4 点前后**：「模糊」「记得」的 due 对齐凌晨 4 点（`SRS.review` 已保证），首页复习数不包含明天的卡 → Task 1 测

### Task 1: `study.js` 复习规则

**Files:** Modify `study.js`；Test `tests/study.test.js`

**Interfaces（全局 `STUDY`，新增）：**
- `reviewQueue(cards, now, cap = 50) -> string[]`：`!known && srs.due <= now` 的卡的 `w`，按 `srs.due` 从早到晚，最多 cap 个
- `afterGrade(queue, i, grade, requeued: Set<string>) -> number`：评完第 i 张后，`grade === "again"` 且这张没再出现过 → 把它的 w 加到 `queue` 末尾、加进 `requeued`；返回下一张的下标 `i + 1`（`queue` 和 `requeued` 原地改，调用的人拿着这两个对象）
- `intervalLabel(srs, grade, now) -> string`：用 `SRS.review` 算；`again` →「10 分钟」；其他 →「N 天」（N = 新 interval）。`study.js` 里 `SRS` 从全局（浏览器）或 `require("./srs.js")`（Node）拿
- `firstSource(card, songs) -> {song, li} | null`：第一个"歌还在、且 `li < song.lines.length`"的出处
