# M5.5 后半 · 皮肤 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 丁香、夜曲、晨雾三套皮肤做成独立文件，加新皮肤只新增文件 + registry 加一行；设置 › 皮肤页、解锁弹窗、颜色自动检查；这次不做兑换码和开发者模式。

**Architecture：** 每个皮肤是 `skins/<id>.js` 里的一个纯数据对象，`skins/registry.js` 列出 id 并按顺序同步加载这些文件；`skins/skin.js`（全局 `SKIN`）把颜色对象转成 CSS 变量、生成全部皮肤的样式表、切换 `<html data-skin>`；`skins/unlock-rules.js`（全局 `UNLOCK`）定义解锁条件。组件只读 CSS 变量，不认识任何皮肤 id。当前皮肤存在 meta `checkin.theme`，同时抄一份到 localStorage `yc-skin`，让首屏在第一帧就是对的颜色。

**Tech Stack：** 原生 HTML/CSS/JS（`<script src>`，没有构建工具）；`node --test`；`tests/browser/run.js`（无界面 Chrome）。

**Spec：** `docs/皮肤系统与兑换码规格.md`（实现方式以它为准）、`docs/打卡与皮肤规格.md`（颜色值、界面）、设计图 `docs/design/skins-home.png`、`docs/design/skins-settings.png`、`docs/数据兼容规则.md`。

## Global Constraints

- 组件代码（`index.html` 的 CSS 和 JS）里**不能出现任何皮肤 id 的判断**，也不能写颜色值；所有差别通过变量体现（规格 2.1）
- 每套颜色必填：`bg surface surfacePress ink ink2 muted rule accent accentPress accentSoft onAccent inverse onInverse danger heroTile heroBtn heroBtnInk songTiles tones shadowStrength`；`songTiles` 至少 2 组 `[底色, 文字色]`；`tones` 6 个
- 对比度：`ink`/`bg`、`ink`/`surface`、`onAccent`/`accent`、`onInverse`/`inverse`、`heroBtnInk`/`heroBtn`、`accent`/`surface` ≥ 4.5；`muted`/`surface` ≥ 3；每个声调色/`surface` ≥ 3
- `modes`：`auto`（要 light + dark）/ `light-only` / `dark-only`；夜曲 `dark-only`、`{type:"streak", value:3}`；晨雾 `auto`、`{type:"songs", value:1}`；丁香 `auto`、`{type:"default"}`
- 「开始今天的学习」按钮：丁香浅色、晨雾浅色是白底主色字；丁香深色、夜曲、晨雾深色是深色底亮色字（设计图）
- 切换皮肤颜色 0.3 秒过渡；开了「减弱动态效果」就直接换
- 数据只加不删；改数据结构要 dataVersion +1、写迁移、加 `tests/fixtures/data-v5.json`
- 界面按设计规范 4.4 视觉对齐：间距只用 4/8/12/16/20/24/32，按钮 ≥ 44px，440×956 浅色 + 深色截图，没有横向溢出
- 这次**不做**：兑换码、开发者模式、`skins/codes.js`、`tools/make-code.js`（规格第 4、5 节，下一次做）
- 版本 v0.33；不提交 mp3 / lrc / 歌词

### Task 2：解锁条件

**Files:**
- Create: `skins/unlock-rules.js`
- Test: `tests/unlock.test.js`；`tests/skins.test.js` 改成读 `UNLOCK.RULES`

**Interfaces:**
- Consumes: `SKIN_DEFS`、`SKIN_IDS`
- Produces: 全局 `UNLOCK`：
  - `RULES[type] = { label(value) -> string, reached(value) -> string, done(ctx, value) -> bool, progress(ctx, value) -> {cur, max} | null }`，`type` 是 `default streak total songs words code`
  - `ctx = { streak, best, total, songs, words }`（当前连续、最长连续、累计打卡、学会的歌、掌握的词）
  - `context({ checkin, songs, cards, today }) -> ctx`：学会的歌 = `STUDY.nextLine(lines 的 text, learned).li === null` 且至少有一句；掌握的词 = `known || srs.reps >= 3`
  - `newlyUnlocked(defs, ctx, unlockedIds) -> [{ id, by }]`：按 `order` 排序，已经解锁的、`code` 类型的不算
- 文字（逐字照抄）：`label`：default「默认皮肤」、streak「连续打卡 ${v} 天解锁」、total「累计打卡 ${v} 天解锁」、songs `v===1 ? "学会第一首歌解锁" : "学会 ${v} 首歌解锁"`、words「掌握 ${v} 个词解锁」、code「用兑换码解锁」；`reached`（解锁弹窗上面那行小字）：「连续打卡 ${v} 天达成」「累计打卡 ${v} 天达成」「学会第一首歌」/「学会 ${v} 首歌」「掌握 ${v} 个词」
- streak 用 `max(best, streak) >= value`（达到过一次就永久解锁），进度显示当前连续 `min(streak, value)/value`
