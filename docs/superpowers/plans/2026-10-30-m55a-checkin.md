# M5.5 前半 · 打卡 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成「今天的学习」就算打卡。首页显示连续天数和累计天数，日历页能看每天的学习量，完成页有本周打卡动画；休息卡能保住连续天数；调试面板可以模拟日期来测跨天。

**Architecture:**
- 打卡规则全部是新文件 `checkin.js` 里的纯函数（全局 `CHECKIN`，Node 测试），包括：什么算打卡、休息卡发放和使用、天数、ISO 周、月历格子、备份合并。数据存在 meta 表的 `checkin` 记录里。
- `index.html` 加一个 `appNow()`（真实时间 + 调试面板设的天数偏移），日期和复习相关的计算都改用它。
- 打卡发生在 `renderDone()`（完成页出现时）。休息卡在启动、切回前台、改模拟日期时由 `CHECKIN.process` 处理。
- 日历是新页面 `calendarView`（DEPTH 1，从首页那一行进入）。

**Tech Stack:** 原生 HTML/CSS/JS，IndexedDB，`node --test`，`tests/browser/run.js`。

**Spec:**
- `docs/第二三阶段开发规格.md`：7.9.1–7.9.5.3、7.9.7（皮肤 7.9.5.4、7.9.5.5、7.9.6 是后半，这次不做），以及第 9 节 M5.5
- `docs/设计规范.md`：4.4、5.1、6.1

## Global Constraints

- "今天"按本地凌晨 4 点换日，统一用 `SRS.today(appNow())`
- 打卡条件：今天到期的复习全部做完（复习数为 0 也算完成），并且新句子学到 `meta.daily.goal`。例外：没有可以学的新句子时（正在学的歌已经学完），只要复习做完就算
- 休息卡：
  - 每周一凌晨 4 点发 1 张，最多存 3 张
  - 功能上线时先送 1 张
  - 漏打的天数 ≤ 手里的张数：每漏一天用一张，那天记为 `rest`
  - 漏打的天数 > 张数：一张都不用，连续天数归零
  - 当前连续天数为 0 时不用
- 首页那一行：
  - 文字「连续 **N** 天 · 累计 **M** 天」
  - 没打过卡时显示「今天开始第一天」
  - 连续断了、今天还没打卡时显示「今天重新开始 · 累计 **M** 天」
  - 火焰用 inline SVG：今天已打卡时 `--accent` 色，没打卡时 `--muted` 色
  - 数字用 Outfit（`.num`），整行可点，进日历页
- 日历格子的颜色深浅，按学习量 = `newWords + reviewed`：
  - 0：`--rule`
  - 1–15：`--accent` 25%
  - 16–40：`--accent` 55%
  - 40 以上：`--accent` 100%，文字用 `--on-accent`
  - 休息日：虚线边框 + 小「休」字，`--muted` 色
  - 今天：外面一圈 2px `--accent` 描边
- 完成页打卡动画：
  - 0.3 秒后，今天的格子用弹簧（`var(--spring)` / `var(--dur-spring)`）放大填色
  - 「连续 N 天」的数字向上翻动
  - 同一天第二次进完成页时直接显示结果
  - 开了减弱动态效果时也直接显示结果
- 颜色只用 CSS 变量（透明度用 `color-mix(in srgb, var(--accent) 25%, transparent)`）
- 间距只用 4/8/12/16/20/24/32（设计规范 4.4）
- 按钮至少 44px 高；按下效果用 `.is-pressed`，新的可点元素要加进 `PRESSABLE`；不用暗幕
- 测试里的句子都是编的；不提交歌词或音频
- 完成后直接合并到 main 并 push，版本号 **v26**（`APP_VERSION`、`sw.js` 的 `VERSION`、debug 测试）

**本计划的决定（2026-10-30 开发者已确认，第 1、7 条按开发者的意见改过）：**
1. **没有词汇包的歌**：规格的例外只写了「歌学完了」，所以没有词汇包、学不了新句子时，只做完复习**不算**打卡。
   - 首页「今天的学习」卡片里要提示「先导入词汇包，才能学新句子和打卡」
   - 旁边放一个按钮，直接打开这首歌的词汇包导入（复用现有的 `data-today="pack"`）
2. **好几周没打开 App**：
   - 中间经过几个周一就补几张，最多 3 张
   - 先发卡，再处理漏打的日子，所以漏打期间经过的周一发的卡也能用上
3. **休息卡提示**：首页那一行下面出现一条提示，离开首页后消失。
   - 漏 1 天：「昨天没学，用了 1 张休息卡，连续天数保住了 · 还剩 X 张」
   - 漏多天：「有 N 天没学，用了 N 张休息卡，连续天数保住了 · 还剩 X 张」
4. **完成页没达到打卡条件时**（比如只复习、没学新句子）：本周日历照样显示，今天的格子是空的，下面写「今天还没打卡」。
5. **日历能往回翻到哪个月**：最早到有打卡或休息记录的那个月；没有记录时只能看本月。
6. **模拟日期**：
   - 调试面板里加四个控件：「−1 天」「+1 天」「回到今天」和一个日期选择框，存在 localStorage `yc-simdays`（整数天数）
   - 只在调试面板打开时生效，关掉调试面板就清零
7. **连续天数断了（为 0）、今天还没打卡、但以前打过卡时**：显示「今天重新开始 · 累计 M 天」，不显示「连续 0 天」。今天打卡后正常显示「连续 1 天 · 累计 M 天」。

## Review Focus

1. **很多天没打开 App**（比如 3 周）：每经过一个周一补一张卡，最多 3 张；漏的天数比卡多时一张都不用，连续天数归零 → Task 1 测 `process: 三周没开`
2. **同一天多次进完成页**（学完后「再学 2 句」）：不重复打卡，只更新当天的学习量，不再播动画 → Task 3 页面测试 `second-done-no-anim`
3. **跨年和月初是星期天**：
   - `isoWeek("2027-01-01") === "2026-W53"`
   - 2026 年 11 月 1 日是星期天，月历前面空 6 格
   → Task 1 测试
4. **App 开着过了凌晨 4 点，或者第二天从后台切回来**：`visibilitychange` 时重新处理休息卡、刷新首页 → Task 3 页面测试 `resume-next-day`
5. **恢复旧版本的备份**（没有 `checkin`），或者同一天一边是 `done`、一边是 `rest`：`done` 优先，其他字段按规格合并 → Task 1 测 `merge`，Task 3 页面测 `backup-roundtrip`

**Interfaces（全局 `CHECKIN`，写法照 `srs.js`：浏览器里是全局，Node 里用 `require`）：**

日期都是 `"YYYY-MM-DD"` 字符串（`SRS.today` 的格式）。

日期工具：
- `addDays(day, n) -> string`
- `weekday(day) -> 1..7`：周一是 1
- `isoWeek(day) -> "YYYY-Www"`：周数补成两位，字符串可以直接比大小

记录：
- `fresh(today) -> rec`：`{ key: "checkin", days: {}, restTokens: 1, lastTokenWeek: isoWeek(today), lastProcessed: addDays(today, -1), bestStreak: 0, unlocked: ["lilac"], theme: "lilac" }`
- `normalize(rec, today) -> rec`：空的或坏的记录返回 `fresh(today)`；坏字段修好
- `qualifies({ due, newLines, goal, finished }) -> boolean`：`due === 0 && (newLines >= goal || finished)`
- `markDone(rec, today, { reviewed, newLines, newWords }) -> { rec, first }`：
  - 把今天记成 `done`，带上这三个数
  - 今天本来就是 `done` 时只更新数字，`first: false`
  - 同时更新 `bestStreak`
- `process(rec, today) -> { rec, used }`，按这个顺序：
  1. 按 `lastTokenWeek` 到今天经过的周数补卡（最多 3 张），更新 `lastTokenWeek`
  2. 找从 `lastProcessed` 的第二天到昨天之间漏打的日子（没有记录的天）
  3. 漏打的天数 ≤ 张数、并且到 `lastProcessed` 为止的连续天数 > 0 时，每天记 `rest`、扣一张
  4. 把 `lastProcessed` 设成昨天
  - 返回的 `used` 是这次用了几张卡；不改传进来的对象

天数：
- `streak(rec, today) -> number`：今天有记录就从今天往回数，没有就从昨天开始；`done` 和 `rest` 都算
- `total(rec) -> number`：只数 `done`
- `best(rec, today) -> number`：`max(bestStreak, streak)`

日历：
- `level(entry) -> 0 | 1 | 2 | 3`：不是 `done` 时为 0；学习量 = `newWords + reviewed`，1–15 是 1，16–40 是 2，40 以上是 3；`done` 但学习量是 0 时算 1
- `weekOf(today) -> string[7]`：这一周周一到周日
- `monthGrid(year, month) -> (string | null)[]`：`month` 是 1–12，周一开头，前面用 null 补齐，长度是 7 的倍数
- `detail(entry) -> string`：
  - `done`：「复习 12 个词 · 新学 4 句、17 个词」
  - `rest`：「休息日」
  - 没有记录：「没有打卡」

备份：
- `merge(local, incoming) -> rec`：
  - `days` 取并集，同一天 `done` 优先于 `rest`
  - `restTokens`、`bestStreak` 取较大值
  - `unlocked` 取并集
  - `lastTokenWeek`、`lastProcessed` 取较晚的
  - `theme` 用本机的
  - 有一边是空的时，用另一边
