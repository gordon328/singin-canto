# M4a · 词汇包 v3 + 每天新学几句 + progress Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 词汇包改成覆盖整首歌的所有词（只有重点词显示下划线，旧词汇包照常用），设置页「每天新学几句」真正存起来，并备好 M4b 要用的 `progress` 和 `daily` 数据结构。

**Architecture:** 词汇包的提示词、导入校验、"一句里每个字属于哪个词"的计算，从 `index.html` 搬到新文件 `pack.js`（全局 `PACK`，纯函数，Node 可测）；`index.html` 里的 `computeLine(li)` 变成 `computeLineFor(cur, li)` 的薄包装。`progress`、`daily` 的读写规则放进新文件 `study.js`（全局 `STUDY`，纯函数），M4b 的学习流程以后也写在这里。页面只负责调用这些函数、存数据库、画界面。

**Tech Stack:** 原生 HTML/CSS/JS，IndexedDB，`node --test`，`tests/browser/run.js`（无界面 Chrome）。

**Spec:** `docs/第二三阶段开发规格.md` 第 1 节（`computeLineFor` 重构）、3.3、3.4、3.5、第 4 节、5.7、9 M4a；`docs/设计规范.md` 5.5（波浪下划线）、5.11（设置页）。

## Global Constraints

- 不把任何歌词或音频提交到仓库；测试数据只用编的句子（`tests/browser/fixtures.js` 的风格）
- 不用框架、不用构建工具；新文件用 `<script src>` 引入，写法照 `srs.js`：IIFE，浏览器里挂全局，Node 里 `module.exports`
- 新提示词：`words` 覆盖歌词里所有不重复的词；30–50 个重点词加 `"key": true` 和 `tip`；口语字 `"oral": true`；去重、顺序随意、不按歌词顺序；不输出完整歌词、不逐句翻译；`summary`、`fix` 不变

- 数据库仍是版本 2，不加表、不动 `songs` 表结构；`daily` 存在 meta 表，key 为 `"daily"`
- "今天"按本地凌晨 4 点换日，用 `SRS.today(now)`
- `goal` 是 1–20 的整数，默认 4；设置页选项 2 / 4 / 6 / 自定义（自定义展开「− 数字 +」，每次 ±1，到 1 / 20 时对应按钮 `disabled` 变灰）——规格 5.7（2026-10-28 补充）

1. **Claude 回复里带了说明文字或 \`\`\`json 代码块**：应该照样导入（从第一个 `{` 到最后一个 `}`）→ Task 1 测 `parsePack: 带代码块和前后说明也能读`

格式示例（示例内容和这首歌无关）：
{"summary":"…","words":[{"w":"今日","jp":"gam1 jat6","zh":"今天","key":true,"tip":"粤语说今日，不说今天"},{"w":"我","jp":"ngo5","zh":"我"},{"w":"佢","jp":"keoi5","zh":"他/她","key":true,"oral":true,"tip":"最常用的粤语口语字之一"}],"fix":[]}
