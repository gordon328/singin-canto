# M2 · 界面改版 + iPhone 适配 + 右滑返回 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把现有页面（首页、播放页、词卡、导入、打轴、词汇包、备份）改成「丁香」设计，修 iPhone 上的已知问题，加上右滑返回；字体和粤拼库改成项目自带。

**Architecture:** 仍是 `index.html` + 少量 .js。CSS 全部改用设计规范的变量（只用变量，不写颜色值）。手势的判断逻辑（拖多远算返回、拖多远算关闭）写成纯函数放进新文件 `gesture.js`，用 Node 测；页面切换用 `history.pushState/replaceState` + `popstate`。浏览器里的行为用一套提交进仓库的无界面 Chrome 测试（`tests/browser/`）检查，每个任务都加自己的检查项。

**Tech Stack:** 原生 HTML/CSS/JS；Node 24（`node --test` 测纯函数，`node tests/browser/run.js` 驱动本机 Chrome 测页面）；Outfit 字体（OFL）；to-jyutping 3.1.1（BSD-2）。

**Spec:** `docs/设计规范.md`（全部）、`docs/第二三阶段开发规格.md` v2 第 2 节、7.3 节、第 9 节 M2；截图 `docs/design/player-wordcard.png`、`docs/design/learn-line-done-edit.png`。

## Global Constraints

- 组件里**只能用 CSS 变量，不能直接写颜色值**（设计规范 2）。变量名和值照抄设计规范 2.1、2.2、2.3、2.4、4.3、6
- 中文只用 `--font-cjk`，粤拼、数字、时间、倍速用 `--font-latin`（Outfit 500/600/700）；不再出现 Noto Serif HK、JetBrains Mono
- 不再从 Google Fonts、jsDelivr 加载任何东西：Outfit 放 `fonts/`，to-jyutping 放 `vendor/`，都带授权文件
- 按钮高度：普通 44–50px，页面底部主按钮 56px；所有按钮按下 `scale(.97)` + press 色，`--dur-fast`
- 页面左右边距 16px（首页 20px），全局 `*, *::before, *::after { box-sizing: border-box; }`
- 输入框字号至少 16px；可点元素 `touch-action: manipulation`；`-webkit-tap-highlight-color: transparent`；整屏高度用 `100dvh`
- `prefers-reduced-motion: reduce` 时去掉位移和缩放，只保留淡入淡出
- 浅色、深色模式都要正常
- 不用 `alert()` / `confirm()`；删除类操作"再点一次确认"
- 不改数据结构，不动 M1 的数据库、`srs.js`、备份格式
- **提交前用 `git diff --cached --name-status` 核对要提交的文件**；测试数据只用编的句子；不提交 mp3、lrc、歌词文本
- 在分支 `m2-ui` 上按任务提交，最后 squash 合并到 `main`，写一条中文 commit

## 计划里替开发者定的事（规格没写清楚，执行前请开发者确认）

1. **「今天的学习」卡片 M2 不做**：它要显示复习数和新学句数，这些数据 M4 才有。M2 的首页是：标题 + 六个声调键帽 + 我的歌 + 浮动「＋ 导入新歌」
2. **声调键帽 M2 固定用 si 这一组**（詩史試時市事），标题「六个声调 · si」；「换一组」和每天轮换是 M3（规格 7.2）
3. **备份**：首页右上角的图标按钮（截图里的下载图标），点开还是现在的备份弹层。M4 做设置页时再搬进设置
4. **「词汇包」和「删除这首歌」**：搬进播放页右上角的「⋯」菜单（规格 9 说右上角有菜单，M3 往里加「校对歌词」）。首页歌曲卡片上不再有删除按钮
5. **每句前面的时间**保留，样式变淡变小，点它从这句开始播放（截图里没有，但去掉后就没法跳到某一句了）
6. **倍速**改成一个按钮，点一下在 1× → 0.8× → 0.6× → 1× 之间切换（截图里是一个「0.8×」按钮）
7. **Safari 里用系统右滑返回时**，页面直接切回，不再播放 App 自己的返回动画（Safari 已经播了一遍系统动画，再播一次会闪）。点左上角返回按钮、在主屏幕 App 里右滑时，播放 App 的返回动画
8. **页面层级只有两层**：首页 ↔ 其他页。导入 → 打轴 → 播放这种连续跳转用 `replaceState`，所以返回总是回到首页

## Review Focus

1. **从播放页返回（按钮、Safari 右滑、主屏幕右滑）时歌必须停**：音乐不能在首页继续响。由 Task 8 的 `back-pauses-audio` 检查覆盖
2. **弹层开着时触发返回**：弹层要关掉、页面回到首页，不能卡住或留下遮罩。由 Task 8 的 `back-closes-sheet` 检查覆盖
3. **很长的歌名、很长的一句歌词**：页面不能出现左右滚动，卡片不能超出右边（旧 bug）。由 Task 4、Task 5 的 `no-horizontal-overflow` 检查覆盖（测试歌名 40 个字）
4. **最后一句歌词被浮动播放条挡住**：滚到底时最后一句要完整露出来。由 Task 5 的 `last-line-visible` 检查覆盖
5. **离线**：改成自带文件后，第一次联网打开之后，飞行模式还能正常显示字体和粤拼。由 Task 2 的 `no-external-requests` 和 `sw-shell-files-exist` 检查覆盖；开发者 iPhone 验收第 9 项再确认一次

**Interfaces:**
- Produces（后面每个任务的 scenario 都用）：
  - scenario 文件导出 `module.exports = { name: string, run: async (b) => void }`
  - `b.nav(path)`：打开 `http://localhost:8080`+path，等页面 `load` 后再等 1500ms
  - `b.ev(expr) -> any`：在页面里执行表达式（支持 Promise），返回 JSON 值

**留给以后**
- 前进动画的 320ms 里页面可以被横向拖动一点（可加 `overflow-x: clip`）
- `history.scrollRestoration` 仍是 auto，iOS 返回动画可能偶尔跳一下
- 主屏幕模式下，从左边缘 24px 内点歌词时间可能被当成右滑
- 顶部栏安全区用的是 sticky + `body::before` 遮挡，而不是 `padding-top`（目前状态栏样式下没有影响）
- 打轴做到一半按返回，进度不保存也没有提示（原来就是这样）
