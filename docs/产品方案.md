# 粤语歌学粤语 · 产品方案（v1.1，2026-10-26 更新）

## 定位
- 通过粤语歌学粤语的手机网页应用（PWA），先自用，完全免费
- 用户：零基础的普通话母语者（优先考虑大陆用户）
- 目标：会唱、听懂；核心是帮助记住字词和发音

## 技术
- PWA 网页版，iPhone Safari "添加到主屏幕"使用；不需要苹果开发者账号
- 托管：GitHub Pages（免费），以后可分享链接
- 数据：全部存在手机浏览器（IndexedDB），无服务器；提供导出备份 / 导入恢复
- 开发：AI 写代码，开发者负责提需求和测试，每周 3–5 小时
- 以后用户多了再考虑做原生 App

## 内容来源
- 音频：用户自己的 mp3 / m4a（网易云、QQ音乐、Apple Music 的加密下载不能用）
- 歌词：
  - 导入 mp3 后，自动在 LRCLIB（lrclib.net，免费、无需 key）搜索带时间轴的 lrc 歌词，按时长匹配版本
  - 宽容搜索：歌名+歌手 → 只用歌名 → 简繁转换；服务器繁忙（503）时自动等待重试
  - 搜不到时：导入 lrc 文件，或粘贴纯文本歌词后用"打轴"模式手动对齐
  - 2026-10 实测：经典热门粤语歌覆盖很好；歌名写法必须准确（如"囍帖街"）；部分新歌缺失；大陆能否稳定访问待测
- 词汇包（原"歌曲包"，v1.1 改版）：用户把歌词 + 固定提示词发给 Claude，再把输出粘贴进 App
  - 歌词受版权保护，Claude 不会输出整首歌词或逐句翻译。所以词汇包只包含：30–50 个重点词（粤拼、普通话意思、记忆提示、口语字标记）、错别字更正（每处不超过 4 个字）、整首歌大意（两三句）
  - App 自动在歌词里匹配这些词（长词优先），标上正确读音和下划线；其余字用 to-jyutping 自动粤拼
  - 不依赖行号，任何版本的歌词都能匹配
  - 没有逐句翻译；歌曲页顶部显示整首歌大意
- 自动粤拼：to-jyutping（CanCLID，BSD-2，v3.1.1，jsDelivr 加载，约 270KB，能按词语判断多音字）
- 标准发音：iPhone 自带粤语（香港）语音合成；以后可补充真人录音（如 Wikimedia Commons 开放录音）

## 学习体验
- 歌词：逐字粤拼（Jyutping），按六声调上色；粤拼可隐藏；重点词有下划线，点开看释义和记忆提示
- 播放：点句跳转；单句循环（一直循环，手动取消）；慢放 0.6x / 0.8x / 1x；点字听标准发音；点字可改读音
- 每段学习流程（2–4 句一段）：先听 → 学这段里的重点词 → 逐句跟读 → 小测 → 跟唱 → 生词进入复习卡片
- 记忆卡片：以词为单位；词汇包里的重点词，可手动添加；学过的词在其他歌里自动跳过；正面汉字，背面粤拼 + 发音 + 释义 + 出处（可播放原唱那句）；评分"忘了 / 模糊 / 记得"，间隔复习算法自动排期
- 小测验：听音选字、看字选粤拼、听辨声调、歌词填空；不做语音识别打分
- 入门单元：6–8 课（粤拼声母韵母、六声调听辨、普粤对应规律），建议先学，可跳过，学歌时可随时跳回
- 首页：六声调示例 + 歌曲列表 + 导入新歌 + 备份

## 开发阶段
1. 播放器：歌词同步、粤拼与声调颜色、循环、慢放、点字发音、LRCLIB 搜索、打轴、词汇包导入与校验、备份。**原型已完成**；还需要发布到 GitHub Pages 并加上 PWA 支持
2. 记忆卡片：每段学习流程、生词卡、间隔复习
3. 入门单元 + 小测验

数据结构从第一阶段起就为后续阶段设计（每个词记录出处歌曲和句子）。
