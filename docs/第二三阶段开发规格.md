## 0. 背景

开发者是**粤语零基础**的普通话母语者，主要用 iPhone（17 Pro Max）。他想要的不是多邻国那种游戏化，而是**能帮助记忆、循序渐进**的学习方式：

> 从歌的第一句开始，先一个词一个词地学，类似 flash card；学会读音了换下一个词；这句里的词都过了一遍，再把整个句子连起来。每天先复习之前学的，再学新的。每天学几句，也可以选择今天多学几句。

**明确不做的：** 连续打卡天数、经验值、徽章、排行榜、语音识别打分、逐句普通话翻译（版权限制，见 `CLAUDE.md`）。

## 1. 现有代码概况（交接时的状态）

> 以实际代码为准，动手前先通读。

**技术：** 单个 `index.html`，原生 JS，无构建。粤拼库 `to-jyutping@3.1.1`（全局 `ToJyutping`，代码里用 `TJ`）。

**IndexedDB：** 数据库 `yuechang`，版本 1，表 `songs`（keyPath `id`）。

**歌曲对象：**
```js
{
  id, title, artist,
  audio,          // Blob
  audioName, duration,
  lines: [{ t, end, text }],   // 秒
  pack: { v: 2, summary, imported,
          words: [{ w, jp, key, oral, zh, tip }],
          fix:   [{ from, to }] },
  overrides: { "行号:字序号": "jyutping" },
  created, updated
}
```

**可以复用的函数：**

| 函数 | 作用 |
|---|---|
| `computeLine(li)` | 算出第 li 行每个字的读音和所属的词（`items[i].word` 是 `pack.words` 的下标，-1 表示不在词汇包里）。已处理 fix、长词优先匹配、overrides |
| `fixText(text)` | 应用错别字更正 |
| `speak(text, rate)` | iPhone 粤语朗读（zh-HK） |
| `playLine(li)` / `setLoop(li)` | 播放某句原唱 / 单句循环 |
| `openSheet()` / `closeSheet()` | 底部弹出层 |
| `DB.open/all/put/del` | IndexedDB 封装 |
| `buildPrompt(song)` / `importPack(raw, song)` | 生成词汇包提示词 / 导入并校验词汇包 |

`computeLine` 依赖全局 `cur`。**请重构成 `computeLineFor(song, li)`**，原函数调用它。学习流程和复习都要在不打开播放器的情况下计算。

## 3. 数据结构

### 3.1 IndexedDB 升到版本 2

**保留 `songs` 表**，新增：
```js
createObjectStore("cards", { keyPath: "w" })   // 记忆卡片
createObjectStore("meta",  { keyPath: "key" })  // 每日计划、入门进度、统计
```
⚠️ 用 `db.objectStoreNames.contains` 判断，**不能删除或重建 songs 表**，否则开发者手机里的歌会丢。

### 3.2 卡片 `cards`

一个词（或单字）一张卡，跨歌曲共享：
```js
{
  w: "海旁",              // 主键：词或单字（繁体）
  jp: "hoi2 pong4",
  zh: "海边",             // 可能为空（词汇包没覆盖的字）
  tip: "…",               // 可能为空
  oral: false,
  sources: [{ songId: "abc", li: 2 }],   // 出处，可多个
  known: false,           // 点了"我早就认识这个词"：不进入复习
  srs: { due, interval, ease, reps, lapses },   // 见第 6 节
  created, updated
}
```

### 3.3 歌曲新增 `progress`

```js
progress: {
  learned: [0, 1, 2, 5],   // 已学会的句子行号
  current: true            // 是否是"正在学的歌"（同一时间只有一首）
}
```

### 3.4 meta 表

```js
{ key: "daily",
  goal: 4,                         // 每天新学几句（设置里可改：2 / 4 / 6 / 自定义 1–20，见 5.7）
  date: "2026-10-27",              // 今天日期；日期变了就重置下面的计数
  newLines: 2,                     // 今天已新学的句数
  extra: 0,                        // 今天"再学 2 句"追加的句数
  reviewed: 12 }                   // 今天复习了几张
{ key: "tones", setIndex: 3, date: "2026-10-27" }   // 首页声调字今天用哪一组
{ key: "intro", done: ["l1", "l2"] }                // 入门单元进度
```

"今天"统一按**本地时间凌晨 4 点**切换（晚上 12 点后学习，仍算前一天）。

### 3.5 备份 v2

备份包含 `songs`（不含音频）、`cards`、`meta`（不含 `backup` 记录）。备份是**文件**，不再复制/粘贴文本（长文本会让手机很卡）。纯函数在 `backup.js`（全局 `BACKUP`）。

**导出**：设置页「导出备份文件」→ 生成 JSON 文件，文件名 `唱学粤语备份-年-月-日.json`（本地日期）。用 `navigator.share({ files })` 调出 iPhone 分享面板（存到「文件」、隔空投送等）；不支持分享文件时退回成直接下载。用户关掉分享面板不算备份。

**上次备份**：每次导出成功记在 meta `{ key: "backup", at }`（只在本机，不进备份文件）。设置页显示「上次备份：今天 / 昨天 / N 天前」，从没备份过显示「还没有备份过」；超过 7 天（或从没备份过且有歌）用提醒颜色 `--danger`。新设备从备份恢复时，如果本机没有记录，用备份文件的 `exported` 时间。

**恢复**：「从文件恢复」→ 文件选择器选 `.json` 文件 → 读取后先弹出摘要（备份日期、几首歌、几张卡片），点「恢复」才合并。文件格式不对时在按钮旁提示原因（文件是空的 / 不是备份格式 / 不是唱学粤语的备份文件 / 没有歌曲列表）。

**没有音频的歌**（备份不含音频）：首页歌曲列表上方提示「N 首歌没有音频，请在「编辑歌曲」里重新选择音频」；歌曲页顶部提示同样的话，带「编辑歌曲」按钮。

合并规则：
- 兼容 v1 备份
- cards 按 `w` 合并，保留复习进度更靠后的（`srs.reps` 大的，相同时取 `updated` 新的）；sources 合并去重
- 歌曲的 `progress.learned` 取并集

## 4. 词汇包 v3：覆盖整首歌的词

### 4.1 为什么要改

新学习流程要求**每句里所有还没学过的字和词都做成卡片**（开发者确认的决定）。零基础的人最需要先学"我、你、好、唔"这些常用字。但现在的词汇包只有 30–50 个重点词，其他字没有普通话意思。

### 4.2 新提示词要求

修改 `buildPrompt`：
- `words` 要**覆盖歌词里所有不重复的词**（按词切分，比如「海旁」「好凍」→「好」「凍」由 Claude 判断），每个词写 `w`、`jp`、`zh`
- 其中值得重点学的 30–50 个词加 `"key": true`，并写 `tip`；口语字加 `"oral": true`
- **去重，顺序随意，不要按歌词顺序排列**（避免变相输出歌词）
- 仍然**不输出完整歌词、不逐句翻译**
- `summary`、`fix` 不变
- 格式示例：
  ```json
  {"summary":"…",
   "words":[{"w":"海旁","jp":"hoi2 pong4","zh":"海边","key":true,"tip":"…"},
            {"w":"我","jp":"ngo5","zh":"我"},
            {"w":"唔","jp":"m4","zh":"不","oral":true,"key":true,"tip":"…"}],
   "fix":[]}
  ```

### 4.3 导入逻辑

- `importPack` 读取每个词的 `key` 字段（v2 是把所有词都设成 key，要改）
- 只有 `key: true` 的词在歌词里显示波浪下划线
- 兼容旧的 v2 词汇包：没有 `key` 字段时当作 key
- 歌词里没被任何词覆盖的字：学习时作为**单字卡片**，读音用自动粤拼，意思显示"暂无释义"，并提示可以重新生成词汇包

## 5. 每日学习流程（核心）

### 5.1 首页「今天的学习」卡片

见设计规范 5.4。显示：
- ① 复习：今天到期的卡片数（`!known && due <= 现在`，最多 50）
- ② 新学：今天还要学几句（`goal + extra - newLines`），以及是哪首歌的第几句到第几句
- 按钮「开始今天的学习」

**正在学的歌**：`progress.current` 为 true 的那首。没有的话，用最近导入的歌。歌曲卡片上可以长按或在歌曲页菜单里选「设为正在学」。一首歌学完了（所有句子都 learned），首页提示"这首学完了 🎉 选下一首"并列出其他歌。

没有导入词汇包的歌，「开始今天的学习」前先提示"先导入词汇包"，提供按钮跳过去（复习部分仍然可以做）。

### 5.2 整体顺序

```
开始今天的学习
  → 复习（有到期卡片时）——见第 6 节
  → 新学句子：按顺序找下一句还没学的
       → 学这句的词（一个词一张卡）
       → 整句
       → 下一句……直到今天的数量学完
  → 今日小测（第三阶段，M7）
  → 今日完成页
```

任何时候点左上角 × 或右滑，都回到首页。**已完成的部分立刻保存**：每个词点了"会读了"就建卡，每句点了"这句会了"就标记 learned。下次点「开始今天的学习」从断开的地方继续。

### 5.3 重复的句子（副歌）

一句话的文字（应用 fix 后）和**前面已学会的某一句完全一样**：自动标记 learned，**不占今天的数量**，不进入学习流程，跳到下一句。

### 5.4 学词卡片（每个词一张）

画面见设计截图「学词」。

**这句要学哪些词**：用 `computeLineFor` 得到这句的词（词汇包里的词按词，没被覆盖的字按单字），按出现顺序去重，**排除已经有卡片的**（不管是在复习中还是 known）。标点、空格跳过。

如果这句所有词都学过了：直接进入整句。

每张卡片：
- 顶部：关闭按钮、进度格（这句有几个新词就几格）、`2 / 5`
- 上方一条：「今日第 3 句 · 行過**海旁**風好凍」，当前的词用 `--accent-soft` 底色高亮
- 大卡片：
  - 每个字一列：粤拼（声调色，20px）在上，汉字（72px）在下
  - 声调标签：每个字一个，比如「第 2 声 · 高升」
  - 普通话意思（22px）
  - 提示框：`tip`（没有就不显示）
  - 三个按钮：🔊 圆形大按钮（标准发音）、「逐字听」（一个音节一个音节读，中间停 0.3 秒；2026-10-30 由「慢速再听」改名）、「听原唱」（播放这句原唱一次，0.8 倍速）。发音规则见 7.8
- **卡片出现时自动朗读一次**（iOS 可能拦截第一次自动朗读，被拦就算了，不报错）
- 底部：
  - 深色主按钮「会读了，下一个」→ 建卡（`srs.due = 现在 + 1 天`，对齐凌晨 4 点）
  - 文字按钮「我早就认识这个词」→ 建卡并标记 `known: true`
- 切换到下一张：旧卡片向左滑出，新卡片从右滑入（设计规范第 6 节）

⚠️ 系统朗读可能读错多音字。只有这个词**退回系统朗读**（见 7.8）并且 `ToJyutping.getJyutpingText(词) !== 卡片的 jp` 时，在发音按钮下面小字提示"系统朗读可能不准，以粤拼为准"。用录音时按卡片的粤拼读，不会读错，不提示。

### 5.5 整句

画面见设计截图「整句」。
- 顶部进度格全部填满，右边显示「整句」
- 小字「把这句连起来读」
- 白色大卡片：整句，每个字粤拼（14px）在上、汉字（34px）在下，可以换行

- 底部深色主按钮「这句会了，下一句」→ 停止播放，标记 learned，`daily.newLines += 1`

### 5.6 今日完成页

画面见设计截图「完成」。

  - 主色「还有精神，再学 2 句」→ `daily.extra += 2`，直接进入下一句
  - 白色「回到首页」

## 6. 复习与间隔复习算法

### 6.1 复习页

和 v1 相同：
- **正面**：只显示汉字（大字）+「心里读一遍，再点翻面」
- **背面**：粤拼（声调色）、翻面时自动朗读、意思、提示、出处（哪首歌那一句，「▶ 原唱这句」只播放那一句，用 `t` 和 `end`）
- 三个按钮：**忘了 / 模糊 / 记得**，每个下面显示预估间隔（「10 分钟 / 1 天 / 3 天」）
- 选"忘了"的卡这一轮结束前再出现一次
- 每次最多 50 张
- 出处的歌被删了就不显示出处；出处有多个时显示第一个

### 6.2 算法（`srs.js`）

简化版 SM-2。纯函数 `review(srs, grade, now)`，返回新对象，不修改传入的对象。

```
新卡（学词时点"会读了"）：interval=1, ease=2.5, reps=1, lapses=0, due=明天凌晨 4 点

grade = "again"（忘了）:
  reps = 0; lapses += 1; ease = max(1.3, ease - 0.2); interval = 0
  due = now + 10 分钟

grade = "hard"（模糊）:
  ease = max(1.3, ease - 0.15)
  interval = (reps == 0) ? 1 : max(1, round(interval * 1.2))
  due = 对齐凌晨 4 点(now + interval 天)

grade = "good"（记得）:
  if reps == 0: interval = 1
  elif reps == 1: interval = 3
  else: interval = round(interval * ease)
  reps += 1
  due = 对齐凌晨 4 点(now + interval 天)
```
- interval 上限 365 天
- 写几个测试用例（新卡连续"记得" → 3、8、20 天左右；"忘了" → 10 分钟、ease 下降）

### 6.3 我的生词

设置页或首页加入口「我的生词（N）」：列出所有卡片（汉字、粤拼、意思、下次复习时间），点开可以听发音、取消"已认识"、删除。

> **2026-10-30 更新：筛选和多选**

- **筛选标签**（列表上方一行）：全部 / 学习中 / 已认识 / 今天到期，每个后面显示数量（`SRS.inTab`）
  - 学习中：`known` 不是 true；已认识：`known` 是 true；今天到期：没认识、下次复习时间在下一个凌晨 4 点之前（过期没复习的也算）
  - 有搜索文字时，数量是搜索结果里的数量

- 每次从设置页进来：回到「全部」、搜索清空、不在选择模式
- **多选**：顶栏右上角「选择」，和首页选歌曲的样式、交互一致（圆形勾选框、选中的描边、右上角「完成」）。选择模式下点词是勾选，不打开词卡；顶栏副标题显示「已选 N 个」
  - 多一个「全选」，只选当前筛选结果（标签 + 搜索）里的词；都选上后变成「全不选」
  - 换标签或改搜索后，看不到的词自动取消选中
- **底部操作栏**（选中至少一个词后出现，三个按钮）：
  - 「标为认识」：`known` 设为 true
  - 「取消认识」：`known` 设为 false，复习状态和新学的词一样（`SRS.newSrs`：明天凌晨 4 点开始复习）。单个词弹窗里的「取消已认识」也按这个规则
  - 「删除」（`--danger` 红色）：确认窗「删除 N 个词？删除后它们不会再出现在学习和复习里。」确认后先从列表拿掉，底部显示「已删除 N 个词 · 撤销」5 秒；5 秒后、离开这一页、或 App 切到后台时才真正从数据库删
  - 选中的词都已认识时「标为认识」变灰；都没认识时「取消认识」变灰
  - 标为认识、取消认识、删除之后都退出选择模式；状态本来就一样的词不动

### 7.1 编辑歌曲（原「校对歌词」）

**为什么**：导入的歌词时间轴和 mp3 常常对不上，也会有错字。

**入口**：歌曲页（自由听）右上角「⋯」下拉菜单 →「编辑歌曲」（菜单见 7.6 和设计规范 5.9）。画面见设计截图「校对歌词」。

> **2026-10-27 更新（M3 验收反馈）**：「校对歌词」改名为「编辑歌曲」，功能在下面第 5–7 条之后补充，原有的 1–4 条不变。

**功能：**
1. **整首歌一起挪**：顶部一行「整首歌一起挪」，− / + 按钮每次 0.2 秒，中间显示累计偏移（「+0.4s」）。所有句子的 `t` 和 `end` 一起加减。这是最常见的问题（整首都早或晚），一次就能修好
2. **单句调整**：点某一句展开（同时只能展开一句）：
   - 文字输入框：直接改错字（16px 字号）
   - −0.5 / −0.1 / +0.1 / +0.5 秒微调
   - 「▶ 试听这句」：从这句开始播放，播到下一句开始时停止
   - 「对准现在的歌声」：边听边按，把这句开始时间设为当前播放时间（减 0.15 秒反应时间）
   - 调整后，**前一句的 `end` 跟着更新**，保证句子之间不重叠；时间不能早于前一句的开始
3. 底部有一条简单的播放控制（播放/暂停、进度），方便边听边调
4. 右上角「保存」。不保存直接返回时，提示"有改动还没保存"，给「保存」「不保存」两个按钮（不用 `confirm()`）。**（2026-10-28 M3.12）** 这是确认类弹窗，点外面不关，所以再加第三个文字按钮「继续编辑」（留在编辑页，什么都不做）。系统右滑返回时也会推回编辑页并弹出这个提示
5. **歌名、歌手、音频**（页面最上面）：歌名、歌手两个输入框；「更换音频」选一个新的音频文件（没有音频时按钮叫「选择音频」）。换音频时**歌词、时间轴、学习进度、手动读音、词汇包都保留**。换了之后底部播放条马上播新音频，方便对时间；保存时才真正替换，不保存就还是原来的音频。歌名留空保存时用「未命名」
6. **歌词的顺序由时间决定**：不做拖动排序。保存时按开始时间自动排好
7. **展开一句后，多出四个操作**：
   - 「在下面插入一句」：新的一句是空的，时间放在这句和下一句开始时间的中间（最后一句时，放在这句开始和结束的中间），自动展开并聚焦输入框
   - 「从这里拆开」：在输入框里光标的位置把这句拆成两句；第二句的开始时间取这句开始和结束的中间。光标在最前或最后时提示"把光标放到要拆开的位置"
   - 「合并到上一句」：两句的文字连起来（中间加一个空格），时间用上一句的开始、这句的结束。第一句没有这个按钮
   - 「删除这句」：先弹确认窗（见 7.5），删掉后上一句的结束时间延长到这句的结束
   - 这四个操作之后，**已学会的句子（`progress.learned`）、手动改过的读音（`overrides`）、生词卡片的出处（`sources` 的 `li`）里的行号都要跟着更新，不能错位**：
     - 插入：新句子不算学会；后面句子的行号 +1
     - 拆开：两句都继承原来的"已学会"；手动读音按字的位置分到两句
     - 合并：两句都学会了，合并后才算学会；手动读音都保留（第二句的字序号往后挪）
     - 删除：这句的学会记录和手动读音删掉；指向这句的卡片出处去掉（卡片本身保留）
     - 改过文字的句子，手动读音照旧清掉
8. 保存时有空的句子：自动展开那一句，提示「第 N 句是空的」

**改了文字以后**：
- 这句的读音重新计算；`overrides` 里这句的手动读音清掉（字的位置可能变了）
- 如果这句已经 learned，保持 learned

### 7.8 标准发音用单音节录音（2026-10-30 新增，v24）

- 录音来自 [Cantone 数据集](https://huggingface.co/datasets/AlienKevin/cantone)（AlienKevin，**MIT 授权**），开发者试听 10 种声音后选了 **Amazon Hiujin**（女声，3884 个音节，6 个声调都有）。转成 16kHz 单声道 32kbps mp3，放在 `audio/hiujin/音节.mp3`（共约 7.7MB），授权见 `audio/LICENSE`。这些是 MIT 授权的单音节录音，不是歌曲，可以进仓库
- `voice.js`（全局 `VOICE`）：音节清单 `HAS`、`plan(jp)`（每个音节都有录音才返回音节列表，否则 null）、`trimRange`（解码后剪掉头尾静音）、`GAP`
- 用在：首页声调键帽、点字词卡（整个词和单个字）、我的生词、学词卡片（自动读、🔊、逐字听）、复习翻面和 🔊；以后的入门课也用它
- 播法（Web Audio 按时间拼接）：
  - **正常**：音节连着读，中间停 **0.05 秒**（先试，开发者听过再决定多字词要不要换回系统朗读）
  - **逐字听**：中间停 **0.3 秒**
- 一个词里**有任何一个音节没有录音**（比如「唔 m4」），整个词退回系统朗读（`speechSynthesis`，zh-HK，语速和以前一样）
- 按需下载：第一次读到某个音节才下载；`sw.js` 把 `audio/` 存进单独的缓存 `voice-hiujin-1`（先用缓存，换版本不删），以后没网也能听。为了离线也能用，提前下载：打开 App 3 秒后下载 8 组声调字和所有生词卡片的音节，打开一首歌时下载这首歌所有字的音节
- iPhone 静音开关打开时也要有声音：`navigator.audioSession.type = "playback"`
- 整句的「标准慢读」也用录音逐字读（停 0.3 秒，标点不读）；这句里有任何一个音节没录音，整句退回系统朗读（0.6 倍速）
- 2026-10-30 开发者试听后决定：多字词**保持录音连读**（0.05 秒），不换回系统朗读

### 7.9 打卡与皮肤（2026-10-30 新增）

> 2026-10-30 由 `docs/打卡与皮肤规格.md`（开发者和 Claude 讨论定稿）合并进来。在 M6 之前作为新里程碑 M5.5 来做，见第 9 节。动手前先通读现有代码，以实际代码为准。

#### 7.9.0 为什么做这个

开发者用了一段时间后，希望有一点**坚持下去的动力**。讨论后的方向：

- 做：**打卡日历**、**连续天数**、**累计天数**、**休息卡**（防止一次意外断掉就放弃）、**用真实学习成果解锁皮肤**
- 不做：金币、商店、经验值、排行榜。理由：奖励要和学习本身挂钩，不能让人为了赚金币而点"会读了"

#### 7.9.1 什么算"今天打卡了"

完成首页「今天的学习」里的**全部内容**，就算打卡：

1. 今天到期的复习全部做完（复习数为 0 时这一项算完成）
2. 新句子学到今天的目标数量（`meta.daily.goal`）

**例外**：如果没有可以学的新句子（正在学的歌已经学完、还没选下一首，或者还没有导入任何歌），只要复习做完就算打卡。

- 打卡发生在今日完成页出现的那一刻
- 同一天学完后再点「再学 2 句」，不会重复打卡，只更新当天的学习量
- "今天"按**本地时间凌晨 4 点**切换（和全 App 一致）

#### 7.9.2 休息卡

- **每周自动获得 1 张**：每周一凌晨 4 点发放。功能上线时先送 1 张
- **最多存 3 张**，满了就不再发放
- **自动使用**：打开 App 时，检查从上次处理到昨天之间有没有漏打卡的日子：
  - 漏打的天数 **≤ 手里的休息卡数**：每漏一天用一张，那天标记为"休息日"，连续天数不断
  - 漏打的天数 **> 手里的休息卡数**：**一张都不用**，休息卡全部保留，连续天数归零
  - 当前连续天数为 0 时，不使用休息卡（没有可以保护的）
- 用掉休息卡时，首页显示一条提示：「昨天没学，用了 1 张休息卡，连续天数保住了 · 还剩 1 张」

#### 7.9.3 天数计算

- **连续天数**：从今天往回数（今天还没打卡就从昨天开始），每天是"打卡"或"休息日"就继续，遇到第一个两者都不是的日子停止。休息日算进连续天数
- **累计天数**：所有"打卡"的天数，**不算休息日**
- **最长连续**：历史上最长的连续天数

#### 7.9.4 数据结构

在 meta 表新增一条：

```js
{ key: "checkin",
  days: {
    "2026-10-30": { type: "done", reviewed: 12, newLines: 4, newWords: 17 },
    "2026-10-31": { type: "rest" }
  },
  restTokens: 2,
  lastTokenWeek: "2026-W44",     // 上次发放休息卡的周（ISO 周）
  lastProcessed: "2026-10-31",   // 已处理到哪一天（用于检查漏打卡）
  bestStreak: 9,
  unlocked: ["lilac"],           // 已解锁的皮肤
  theme: "lilac" }               // 当前使用的皮肤
```

**备份**：备份文件包含这条记录。恢复时 `days` 取并集（同一天两边都有时，`done` 优先于 `rest`），`restTokens` 取较大值，`bestStreak` 取较大值，`unlocked` 取并集。

##### 7.9.5.2 日历页

从首页那一行进入，和其他页面一样从右滑入、支持右滑返回。

- **顶部统计**：四个小格，连续天数、累计天数、最长连续、休息卡 ×N（休息卡下面小字：「每周一发 1 张，最多存 3 张」）

  - 周一开头，上方是「一 二 三 四 五 六 日」

## 8. 第三阶段：入门单元 + 小测验

### 8.1 入门单元入口

- 首页加一个区块「入门：粤拼和声调」，显示「已完成 2/8 课」
- 第一次打开 App（还没有任何歌）时，空状态里推荐"先花 15 分钟学入门单元"
- 不强制，可以跳过
- 学词卡片的声调标签可以点，点了跳到第 1 课

### 8.2 课程结构

每课由若干"页"组成，一页一屏，顶部有进度格（和学词卡片一样的样式）。页的类型：

| 类型 | 内容 |
|---|---|
| `explain` | 一小段说明（不超过 3–4 句） |
| `examples` | 一组例字，每个显示汉字 + 粤拼（声调色），点了朗读 |
| `compare` | 两组对比的例字 |
| `quiz` | 几道练习题（题型见 8.4），答完才能继续 |

每课最后 3–6 道练习题。完成后记到 `meta.intro.done`。课程内容写在 `lessons.js`。

### 8.3 八课的内容

所有例字的粤拼**已用 to-jyutping 核对过**，例字和读音不要改，说明文字可以润色。

> 单字朗读偶尔会选错多音字的读音，例字都选了读音单一的常用字。开发者测试发现某个字读得不对，换一个同音字即可（用 `ToJyutping.getJyutpingCandidates()` 确认只有一个读音）。

**第 1 课 · 六个声调**
- 说明：粤语有六个声调，用数字 1–6 写在粤拼后面。普通话的四声和粤语声调没有对应关系，要重新学。App 里每个声调一种颜色。
- 音高（1–5，5 最高）：
  | 声调 | 名称 | 音高 | 说明 |
  |---|---|---|---|
  | 1 | 高平 | 55 | 又高又平，像唱歌拉长音 |
  | 2 | 高升 | 35 | 从中往上扬，有点像普通话第二声 |
  | 3 | 中平 | 33 | 中间高度，平平地读 |
  | 4 | 低降 | 21 | 最低，往下沉 |
  | 5 | 低升 | 13 | 从低往上扬，比第 2 声起点低 |
  | 6 | 低平 | 22 | 偏低，平平地读 |
- 例字：詩 si1、史 si2、試 si3、時 si4、市 si5、事 si6
- 练习：听辨声调（si 这一组）

**第 2 课 · 声调听辨练习**
- 说明：多听几组，耳朵会慢慢分出来。最容易混的是 2 和 5（都往上扬）、3 和 6（都是平的），注意起点高低。
- 例字组：7.2 表格里的 fu、fan、ji、jau、wai 五组
- 练习：听辨声调 6 题（混合各组）；`compare` 页对比 2 vs 5、3 vs 6

**第 3 课 · 入声：短促的字**
- 说明：粤语有一类字以 -p、-t、-k 结尾，读得很短，像突然收住。普通话没有。它们只出现在 1、3、6 三个声调上。
- 例字：色 sik1、錫 sek3、食 sik6；十 sap6、一 jat1、六 luk6；八 baat3、百 baak3、白 baak6
- `compare`：買 maai5 / 賣 maai6
- 练习：看字选粤拼（干扰项用同音不同韵尾，比如 sap6 / sat6 / sak6）

**第 4 课 · 声母：和普通话不一样的地方**
- b/p、d/t、g/k 和普通话一样，一个不送气、一个送气
- **j = 普通话的 y**：魚 jyu4、人 jan4
- **z、c、s** 同时对应普通话的 zh/ch/sh 和 z/c/s，粤语不分平翘舌：張 zoeng1、吹 ceoi1
- **ng-**：我 ngo5、眼 ngaan5、牛 ngau4
- **gw、kw**：瓜 gwaa1、誇 kwaa1
- 练习：看字选粤拼

**第 5 课 · 韵母：长短元音和 -m 结尾**
- **aa 长音，a 短音**：三 saam1 vs 心 sam1
- **-m 结尾**，嘴巴要闭上：心 sam1、三 saam1
- **oe / eo**：靴 hoe1、張 zoeng1、出 ceot1、去 heoi3
- **yu**：像普通话的 ü：魚 jyu4、雪 syut3
- `compare`：三 saam1 / 心 sam1
- 练习：听音选字

**第 6 课 · 普粤读音对应规律**
- 普通话 h（hu-）→ 粤语常读 f：花 faa1、化 faa3、婚 fan1、歡 fun1
- 普通话 -an → 粤语常读 -aan：山 saan1、班 baan1、晚 maan5
- 普通话 r → 粤语读 j：人 jan4、熱 jit6、讓 joeng6
- 普通话 q/x 的一些字 → 粤语读 h：去 heoi3、氣 hei3、喜 hei2
- 普通话 w 的一些字 → 粤语读 m：忘 mong4、望 mong6、文 man4
- 普通话 -ai 的一些字 → 粤语读 -oi：愛 oi3、害 hoi6、代 doi6、來 loi4
- 普通话 j 的一些字 → 粤语读 g：家 gaa1、價 gaa3、解 gaai2、街 gaai1
- 强调"是'常常'，不是'一定'"
- 练习：看字选粤拼

**第 7 课 · 常用粤语口语字**
- 嘅 ge3 · 的；咗 zo2 · 了；啲 di1 · 一些；佢 keoi5 · 他/她；唔 m4 · 不；係 hai6 · 是；喺 hai2 · 在；冇 mou5 · 没有；睇 tai2 · 看；嘢 je5 · 东西；點 dim2 · 怎么；乜 mat1 · 什么
- 短语（整句朗读）：早晨 zou2 san4（早上好）、多謝 do1 ze6（谢谢，收到礼物时）、唔該 m4 goi1（谢谢，别人帮忙时；也是"劳驾"）、飲茶 jam2 caa4、返屋企 faan1 uk1 kei2（回家）、廣東話 gwong2 dung1 waa2
- 课程结束时，这 12 个口语字**自动建卡**（已有卡片的跳过；`tip` 写"来自入门第 7 课"）
- 练习：看字选意思、听音选字

**第 8 课 · 为什么粤语歌好学声调**
- 粤语歌填词讲究"协音"：字的声调高低大致和旋律音高一致。高平的第 1 声常落在高音，低降的第 4 声常落在低音。**记住旋律，就记住了声调。**
- **不要引用具体歌词**（版权），只说"学歌时留意：唱得高的字，粤拼常是 1、2 声；唱得低的字，常是 4 声"
- 结尾引导去学第一首歌

### 8.4 小测验题型

四选一（声调题六选一），点了马上显示对错：
- 答对：选项变绿，短暂提示后下一题
- 答错：选错的变红、正确的变绿，显示正确粤拼，「再听一次」，点「继续」才往下
- 做完显示"答对 4/5"，**不打分、不给星星**

| 题型 | 题目 | 选项 | 用在哪里 |
|---|---|---|---|
| 听音选字 `listen` | 自动朗读一个词，可重播 | 4 个词 | 入门、今日小测 |
| 看字选粤拼 `jp` | 显示汉字 | 4 个粤拼（声调色） | 入门、今日小测 |
| 听辨声调 `tone` | 朗读一个字 | 1–6 声六个键帽（复用声调键帽样式） | 入门第 1、2 课 |
| 看字选意思 `meaning` | 显示汉字 | 4 个普通话意思 | 第 7 课、今日小测 |
| 歌词填空 `blank` | 播放原唱这一句，显示这句，其中一个词变成空格 | 4 个词 | 今日小测 |

**干扰项：**
- `jp`：优先"同音不同调"，其次 `getJyutpingCandidates` 的其他读音，再次其他词的粤拼；不能重复
- `listen` / `blank` / `meaning`：优先同一首歌里字数相同的其他词，不够从卡片库取，再不够减为三选一；`meaning` 跳过没有释义的卡片
- `tone`：只用入门课的例字，**不对歌词里的任意字出声调题**

**朗读可靠性：**`listen` 和 `tone` 只对 `ToJyutping.getJyutpingText(词) === 卡片 jp` 的词出题，否则改出 `jp` 或 `meaning`。

### 8.5 今日小测

- 时机：今天的新句子学完后、完成页之前（开发者确认的决定：不在每句后面考）
- 用**今天新学的词**出 3–5 题；题型混合，至少 1 道 `blank`（唯一用到原唱的题型）
- 今天没学新词（比如只做了复习）：跳过
- 答错的词：`srs.due = 现在`，今天复习时再出现（如果复习已经做完，首页复习数会 +1）
- 点「再学 2 句」后学完的那部分，也会再来一次小测
